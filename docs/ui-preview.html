dsh-model-router 已并入官方输入栏的「模型」格（就是原来选模型/思考等级的那个位置）：点开是同一个弹窗，上半部分是官方的本会话模型 + 推理等级，下半部分是插件自己的路由设置。渲染的就是插件里那份 CSS，只把主题变量换成了近似值；鼠标停在任意控件上会显示解释。
模型池不再单独列一段：每一行模型的右半边就是那个「模型池」小胶囊，点一下加进/移出，进了池子的模型才会在它下面展开定位 / 价格 / 视觉那一行——一份列表同时干两件事，菜单因此短了一半。
官方那格没被声明时（老版本 / 别的宿主），插件会退回输入栏右侧的小胶囊，这时模型池才会单独成段。
